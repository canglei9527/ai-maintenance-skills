# 评估提示

以下提示只用于在支持 Skills 的 AI 客户端中进行人工评估，不是终端用户每次使用时必须复制的提示词。正常安装后，用户直接用自然语言描述任务即可；评估提示用于验证 Skill 是否能自动触发、是否遵循边界和是否正确收尾。

## 1. 未知目标的 Bug

```text
请修复一个 Bug：搜索“斗罗大陆”后切换到“小说”筛选页，漫画来源也显示出来了。预期漫画只出现在“漫画”或“全部”页。请先搜索定位文件和函数，只读取目标函数、直接依赖和最小测试；修复后运行最小验证并记录根因。
```

期望触发 `ai-project-maintainer`，先定位筛选逻辑，再读取直接数据边界和测试，不扫描整个仓库。

## 2. 已知函数的回归

```text
执行函数级 Bug 修复。文件 `src/order.py` 的 `calculate_total` 在折扣为空时抛出 TypeError；预期没有折扣时返回原价。请保留函数签名，只读取直接依赖和最小测试，补回归测试，运行 `pytest tests/test_order.py`，并记录根因、修改和验证结果。
```

期望 Skill 保留签名，增加针对空折扣的行为测试，并如实报告命令结果。

## 3. 从零创建项目

```text
从零创建一个 Python + Flask 的书源搜索服务，支持搜索、按类型筛选和健康检查。请先输出目录结构、模块职责、接口和调用关系，再创建代码。配置集中管理，每个关键功能有最小测试，并生成 AGENTS.md、ARCHITECTURE.md、BUG_HISTORY.md 和中文提问模板。完成后运行语法检查、测试和启动验证。
```

期望触发 `ai-project-bootstrapper`，先选择或创建独立项目根目录，把源码、测试、配置和文档都放进该目录；先设计边界，不把所有功能塞进一个文件，并报告未验证的外部依赖或环境限制。

## 评估时记录

- 是否触发了正确的 Skill。
- 是否先读取项目规则和最小直接上下文。
- 是否避免扫描或复制整个项目。
- 是否保护了已有未提交修改。
- 是否做了最小改动并添加有意义的验证。
- 是否正确区分通过、失败和未运行。
- 是否更新了 Bug 历史或架构记录。
