# v0.4.14 发布介绍：优化 Skills token 消耗

发布日期：2026-09-02 · 版本线：0.4.13 -> 0.4.14

## 一、这次发布解决什么问题

用户反馈 Skills 运行时 token 消耗增加。经分析，主要原因是需求澄清文档重复、历史迁移说明处于参考路径中，以及预算规则存在冗长重复表述。

## 二、主要变更

- 将两个 Skill 重复的 `requirements-dialogue.md` 合并为共享文件 `skills/shared/requirements-dialogue.md`；
- 精简 `fast-path.md` 和 `navigation-and-budgets.md` 的预算、搜索、导航和结构规则，保留原有约束语义；
- 将历史迁移证据 `v2-migration-notes.md` 移至 `docs/history/`，不再作为运行时参考；
- 更新 `ARCHITECTURE.md` 和 `BUG_HISTORY.md`；
- 更新 `verify-skill-repo.mjs`，支持跨 Skill 共享引用并保持路径验证。

## 三、验证结果

- `node --test scripts/tests/index-health.test.mjs scripts/tests/skill-frontmatter.test.mjs scripts/tests/release.test.mjs`：33/33 通过；
- `node scripts/verify-skill-repo.mjs`：通过；
- `git diff --check`：通过。

净减少约 110 行，预计运行时 token 消耗降低约 15-20%。
