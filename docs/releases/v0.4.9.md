# v0.4.9 发布介绍：轻量索引健康检查

发布日期：2026-08-27 · 版本线：0.4.8 → 0.4.9

## 一、这次发布解决什么问题

`ai-context/INDEX.md` 能表达用户任务到第一入口和聚焦测试的路由关系，但完全依赖人工维护。文件移动后本地路径可能静默失效，审核元数据不可见，同时把调用关系写进 Markdown 会复制易变化的机械代码事实。本版本增加轻量、无依赖的只读健康检查器，验证本地引用存在性和审核元数据新鲜度，并保持 Markdown 与代码图工具的边界清晰。

## 二、具体改动

### 1. 索引健康检查器

新增 `scripts/index-health.mjs`，从 `ai-context/**/INDEX.md` 表格反引号单元提取项目相对路径，验证：

- **路径安全边界**：拒绝绝对路径（POSIX 和 Windows）、词法越界（`../` 同前缀兄弟目录）、符号链接/目录联接逃逸项目根
- **目录边界保护**：验证 `ai-context` 目录自身的真实路径，越界时拒绝递归和读取
- **审核元数据验证**：SHA 前缀匹配（大小写不敏感，支持完整或缩写）、审核日期新鲜度（默认 90 天阈值）
- **旧索引兼容**：没有元数据的旧索引保持 VALID，不强制升级

### 2. 路径提取增强

- 支持单双引号包裹的带空格路径（如 `"tests/My Test.js"` 或 `'docs/My File.md'`）
- 识别常见无扩展名项目文件（Dockerfile、Makefile、Procfile、Gemfile、Rakefile、Vagrantfile）
- 命令解析容错，提取引号内路径

### 3. 状态报告

- `VALID`：所有引用存在，元数据新鲜或不存在
- `UNRESOLVED`：缺失、绝对或越界路径（CLI 退出码 1）
- `STALE_REVIEW`：提交变化、非法 SHA 或日期超过阈值（CLI 退出码 0，不阻塞）

### 4. 集成与文档

- 命令行：`node scripts/index-health.mjs <project-root>`
- GitHub Actions CI：已集成到 verify workflow
- 仓库验证：已纳入 `scripts/verify-skill-repo.mjs`
- 新增仓库根 `ai-context/INDEX.md` 和 `examples/minimal-project/ai-context/INDEX.md`
- 更新 `ARCHITECTURE.md`、`BUG_HISTORY.md`、`README.md` 和维护/引导 Skill 导航参考

## 三、测试覆盖

- **33 个集成测试**：索引 23 + frontmatter 5 + release 5

## 四、设计约束

- Markdown 表格路径提取保持轻量简单协议
- 不支持 shell 变量展开、转义序列或嵌套引号
- 复杂命令语法建议使用独立反引号单元或项目自有验证器
- 调用关系与影响范围分析留给源码工具或可选代码图工具

## 五、兼容性

无破坏性变更。旧索引（无元数据）保持完全兼容，Node.js 16+ 依赖保持不变。
